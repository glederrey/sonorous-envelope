## Feedback for Claude Code

1. **`/m/<id>` panel.** Rename sits with the playback controls; Gael would rather not have it there. After a rename is saved, the rename field stays open instead of closing. Gael finds the buttons need visual work and is handling it with you directly.
2. **Deleted moment link.** After Delete in `/saved`, the old `/m/<id>` link shows a generic 404 page. The brief expected the link to "say not found". If a plain 404 is intended, fine; otherwise a short "This moment was deleted or does not exist" page would be clearer.
3. **Guest limit: greyed buttons, no line.** After many fast presses the guest's emoji buttons grey out; Gael saw no slow-down line. Expected: a slow-down line past the limits (1 per 2 s, 10 a minute). Either the line is missing, or greying (the 2 s spacing) is all that was reached; worth checking the 10-a-minute line appears.
4. **Bookmark line after "Already saved".** The second press says "Already saved as …" and still offers Rename (it works). Fine; not yet checked whether the line goes away by itself if not used.
5. **Turns are messages.** Two `set_sound` calls in one message both returned the same `turn` (5, and 13). So the 5-turn spacing for the AI's own saves is 5 messages. The tool says "at most once every 5 turns"; maybe say "5 messages" or "5 turns of the conversation" so the model does not count calls.
6. **Order of `save_moment` and `set_sound`.** In test 4 I sent `set_sound` (new sound) and `save_moment` in the same parallel batch, so the save could have frozen the old state. The refusal was correct either way. A line in `save_moment`'s description ("call it after the set_sound for that sound has returned") would prevent this.
7. **No note for the rate glide.** A tempo change returns "tempo X to Y: it glides over N s"; an arp rate change with a transition returns nothing about the stepping. A matching note ("rate 1/4 to 1/16: steps over 12 s") would help.
8. **`synth.arp.rate` seems sticky.** The `synth` description says it replaces the mood's output "for this call only", but rate 1/16, sent at turn 12, still played at turn 13 after a new mood (calm 0.92, then calm 0.45 with `arp.on: true`). It went back to 1/4 only when I sent `rate: "1/4"`. If arp settings are meant to stay, the description should say so (as it does for stack, pad and LFOs).
9. **Outside the brief: roughness vs. tension on the drone.** The calm drone read `tension: 0` (pass) but `sound.roughness: 0.58`, while the gentle arp sounds read 0.19–0.29. A drone at level 0.6 counting as rough looks off if roughness tracks dissonance.
10. **Outside the brief: warmth and spontaneity reads.** Calm drone: warmth sent 0.65, read 1.0 (`reads_why: "lifted by soft_timbre, darkness"`, a gap of 0.35). Tense sound: warmth sent 0.4, read 0.68. A regular 1/16 up_down arp read spontaneity 0.77 against 0.42 sent (`"lifted by timing_irregularity, note_order"`), though nothing in it was irregular. I did not correct these, to keep the tests clean.
